## Project Description
This repository contains my personal portfolio website created to present my academic background, projects, technical skills, and experiences. 

The website highlights my progression through the 2-year intensive preparatory cycle and into the engineering speciality cycle in AI & Applications. It also showcases **CourSpace**, my preparatory cycle capstone project (Prepanova), along with an interactive screenshot gallery, academic coursework, and a functional bilingual interface.

---

## Technologies Used
- **HTML5:** Semantic structure and accessible markup
- **CSS3:** Custom responsive layout, CSS variables, typography, and RTL styling
- **JavaScript (Vanilla):** DOM manipulation, bilingual language switcher, interactive gallery & lightbox modal, and client-side form validation
- **Google Fonts:** Inter, Space Grotesk, and Cairo (Arabic)

---

## Implemented Features
- **Bilingual Interface:** Full English and Arabic versions with RTL layout support, custom typography (Cairo), and persistent language preferences via `localStorage`.
- **Responsive Design:** Mobile-first layout adaptable across smartphones, tablets, and desktop displays.
- **Academic Background Breakdown:** Distinct presentation of the 2-Year Preparatory Cycle and the Engineering Speciality Cycle (AI & Applications).
- **CourSpace Project Showcase:** Detailed project overview featuring an interactive image gallery, thumbnail previews, and a fullscreen lightbox modal.
- **Technical Skills Overview:** Categorized skill cards spanning AI & Machine Learning, Web & Mobile, Cybersecurity foundations & Blockchain, Databases, and Algorithms.
- **Experience & Activities:** Dedicated cards highlighting an internship at Algérie Télécom and volunteer organization work at NCASE'24.
- **Interactive Contact Section:** Clean contact form with real-time field validation and direct social links.
- **Smooth Navigation & Scroll Effects:** Fixed header with dynamic shadow, active link highlighting, and subtle scroll reveal animations.
